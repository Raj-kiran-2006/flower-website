# Flower Website

A modern and elegant flower shop website for showcasing floral arrangements, bouquets, seasonal collections, and special occasion gifts.

## Overview

This project is a responsive landing page for a flower business that helps customers:

- browse featured bouquets and arrangements
- view seasonal and special occasion collections
- learn about the flower shop brand and story
- contact the store or place an order
- explore premium floral products on desktop and mobile

## Features

- Clean, premium design with floral color palette
- Responsive layout for mobile, tablet, and desktop
- Hero section with promotional offers
- Featured products and category cards
- Seasonal collection highlights
- About section and business story
- Contact and order inquiry section
- Easy-to-customize HTML/CSS/JavaScript structure

## Tech Stack

- HTML5
- CSS3
- JavaScript
